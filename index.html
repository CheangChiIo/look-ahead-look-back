Method overview

General Context is cached once; Instance Context is refreshed at each action chunk.

Virtual-gripper annotation

Two virtual jaws represent opposing contacts; bidirectional tracking maintains the grasp reference through occlusion.

No contactVisible contactOccluded contact

Contact and visibility are estimated separately.

Follow one action-chunk boundary +
  1. Preplay. Predict the interaction from current observations and General Context.
  2. Acquire. Compare the preplay with the demonstration to acquire Instance Context.
  3. Condition. Use both contexts for video features and action generation.
  4. Execute. Observe and repeat after each action chunk.

Backbones stay frozen; no deployment-time parameter updates.
